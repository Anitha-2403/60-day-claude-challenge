# Day 48 – AI Model Comparison Dashboard

## 📌 Challenge Overview

Today, I completed **Day 48** of the **#60DayClaudeChallenge** by building an **AI Model Comparison Dashboard** using **HTML, CSS, JavaScript, and Claude AI**.

The application helps users compare different AI models based on multiple criteria such as performance, pricing, reasoning ability, coding, context window, multimodal support, and other important features. 
It provides an interactive dashboard to make selecting the right AI model easier.

---

## 🎯 Objective

The objective of this project was to design an AI-powered dashboard that enables users to compare AI models using customizable criteria and make informed decisions based on their specific needs.

---

- Claude AI
- Prompt Engineering

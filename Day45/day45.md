# Day 45 – AI Decision Strategist

## 📌 Challenge Overview

As part of the **#60DayClaudeChallenge**, I built an **AI Decision Strategist** application using **Claude AI**. 
This interactive web application helps users analyze difficult decisions by comparing different options, identifying hidden assumptions and biases, evaluating decision criteria, and providing a structured recommendation with an actionable 7-day plan.

---

## 🎯 Objective

The objective of this challenge was to design a decision-support dashboard that guides users through a structured decision-making process and presents the results in a clear, interactive, and visually appealing format.

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Claude AI

---

## ✨ Key Features

- Interactive Decision Report Dashboard
- Real Decision Summary
- Case for Each Option Analysis
- Assumption & Bias Detection
- Decision Matrix with Animated Score Bars
- Premortem Analysis
- 7-Day Decision Test Plan
- AI-Based Final Verdict
- Shareable Summary Cards
- Responsive Dark-Themed UI
- Smooth Animations and Interactive Design

---

## 📚 What I Learned

- How to use prompt engineering to build an AI-powered decision support application.
- How AI can organize complex decisions into a structured analysis.
- The importance of identifying assumptions, biases, and risks before making important decisions.
- How to create an interactive dashboard using HTML, CSS, and JavaScript.
- How to improve user experience through responsive design and modern UI components.

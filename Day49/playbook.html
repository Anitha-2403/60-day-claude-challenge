What is this?

◈ Dashboard

A snapshot of your whole practice — how many prompts you've saved, loops you're running, and sessions you've logged.

▤ Prompt Library

Every reusable prompt you've saved, organized by category and tags. Star the ones you use most, search or filter to find them fast.

✎ Prompt Builder

Write a template once using [bracketed variables] like [topic] or [skill level]. Playbook detects them automatically so you can fill in fresh values every time instead of retyping the whole prompt.

↻ Loop Builder

Model recurring routines (daily habits) or multi-step workflows (ordered sequences) as a visual loop. Useful for things you repeat often, like a weekly learning routine.

▦ Session Logs

A lightweight journal of what you worked on, which tool you used, and how it went — so patterns become visible over time.

Data & privacy

Everything is stored locally in this browser via localStorage. Nothing is sent anywhere. Use Export JSON to back up or move your data, Import JSON to restore it.

# 🤖 Day 40 – AI Assistant Builder

## 📌 Overview

As part of the **#60DayClaudeChallenge**, I built an **AI Resume & ATS Reviewer** using **Claude AI**, **HTML**, **CSS**, and **JavaScript**. 
The assistant analyzes resumes, compares them with a target job description, and provides an ATS-style evaluation with personalized suggestions to help users improve their resumes.

---

## 🎯 Objectives

- Build a custom AI-powered assistant.
- Design a production-quality system prompt.
- Create a modern and responsive user interface.
- Provide ATS-style resume analysis with actionable feedback.

---

## 🚀 Features

### 📄 Resume Analysis
- Upload resume (PDF/DOCX)
- Paste target job description
- ATS compatibility analysis
- Resume text extraction

### 📊 AI Report
- ATS Score
- Strengths
- Skill Gaps
- Missing Keywords
- Resume Improvement Suggestions

### 🎨 User Experience
- Responsive design
- Modern dashboard
- Smooth animations
- Loading and error states
- Documentation panel explaining the assistant

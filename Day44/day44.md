# Day 44 – LinkedIn Profile Optimizer

## 📌 Challenge Overview
On Day 44 of the #60DayClaudeChallenge, I built an **AI-powered LinkedIn Profile Optimizer** using HTML, CSS, JavaScript, and Claude AI.

The application analyzes a LinkedIn profile, provides personalized feedback, suggests improvements, and helps users optimize their profile to attract recruiters and professional opportunities.

---

## 🎯 Objective

The goal of this project was to create an interactive web application that:

- Reviews a LinkedIn profile
- Evaluates different profile sections
- Provides a profile score
- Suggests improvements for better visibility
- Generates a personalized 7-day LinkedIn growth plan

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Claude AI
- Prompt Engineering

---

## ✨ Key Features

- 📊 LinkedIn Profile Score Dashboard
- 🔍 Detailed Profile Analysis
- 🔥 Honest Profile Roast with Suggestions
- 📝 Optimized Headline Recommendations
- 👤 About Section Rewrite
- 💼 Experience Section Improvement
- 🛠️ Skills Recommendations
- 📈 Before vs After Score Comparison
- 📅 7-Day LinkedIn Activation Plan
- 📄 Shareable Summary Card
- 🌙 Dark/Light Mode
- 💾 Local Storage Support
- 📱 Responsive Design

---

## 📚 What I Learned

- How AI can analyze and optimize professional LinkedIn profiles.
- The importance of a strong headline, About section, and relevant keywords.
- How prompt engineering can be used to generate personalized career guidance.
- Improved my frontend development skills by building an interactive web application.
